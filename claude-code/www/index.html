No MCP servers are configured.

Servers are added in the terminal with claude mcp add, which is where a command, its environment and any tokens belong. A switch here lifts a server out of Claude Code's configuration and keeps its definition — secrets included — so switching it back on restores it exactly as it was.

Servers that come from an installed plugin are not listed: those belong to the plugin, and it is the plugin that turns them on and off.

Claude Code reads this before every conversation in this add-on — house rules, how you want things phrased, what to leave alone. Markdown, no schema. A CLAUDE.md in a project folder adds to it rather than replacing it.

Claude Code's own file: the account it is signed in as, the MCP servers, and a record of every folder it has been run in. It writes this itself, so saving is refused while Claude is working, and what you type replaces the file whole. It holds credentials. Editing it wrongly can break the sign-in, which the terminal can put back with claude.
